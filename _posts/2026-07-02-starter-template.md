# Welcome to Your Notes

This is your first note! Here are some tips for getting started:

## How to write notes

1. Create new files in the `_posts` directory
2. Use the filename format: `YYYY-MM-DD-title.md`
3. Add front matter at the top with title, date, and categories
4. Write your content in Markdown

## File structure

```
_posts/
├── 2026-07-02-starter-template.md
└── 2026-07-03-your-next-note.md
```

## Tips

- Use `categories: notes` to organize your posts
- Add `tags` for additional categorization
- Use Markdown formatting for headers, lists, code blocks, etc.
- Your notes will automatically appear on `/notes/` with the newest first

## Example tags

Consider using tags like:
- `thoughts` - Personal reflections
- `learning` - Things you're learning
- `code` - Technical notes
- `ideas` - Creative ideas
- `reference` - Reference material

Happy writing! 📝
